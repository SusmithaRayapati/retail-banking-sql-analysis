# Retail Banking Transaction Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing retail banking transaction data using **SQL** to identify meaningful patterns, customer behavior, transaction trends, and key business insights.

The project demonstrates how SQL can be used to clean, transform, analyze, and extract insights from transactional data.

## 🛠️ Technologies Used

* SQL
* SQL Server
* SSMS (SQL Server Management Studio)

## 🔍 Key SQL Concepts Used

* SELECT, WHERE, ORDER BY
* GROUP BY & HAVING
* Aggregate Functions
* JOINS
* CASE Statements
* CTEs (Common Table Expressions)
* Window Functions
* Ranking Functions
* Date & String Functions
* Subqueries

## 📊 Analysis Performed

* Analyzed banking transactions and customer activities
* Calculated transaction totals and aggregations
* Identified transaction patterns and trends
* Compared customer and transaction-level data
* Used ranking techniques to identify top-performing categories
* Derived business insights from transactional data

## 🎯 Project Objective

The main objective of this project is to strengthen SQL skills by working with real-world-style banking transaction data and converting raw transactional information into useful business insights.

## 📁 Project Files

* `Retail_Banking_Transaction_Analysis.sql` – SQL queries used for analysis
* `Retail_Banking_Transaction_Analysis.pptx` – Project presentation

## 💡 Key Learning

Through this project, I improved my practical understanding of SQL, data analysis, joins, aggregations, CTEs, and window functions while working on a business-oriented dataset.
